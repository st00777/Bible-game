# ADR 0004：讀經進度採 Gemini 網頁版（不對齊惠君 PDF）

- 日期：2026-08-30
- 狀態：已採納（James 拍板；牧師回應「按自己習慣即可」後確認不改）
- 關聯：CLAUDE.md「讀經進度對應（大光教會2026）」全年進度表；memory `reading-schedule-version.md`

## 背景

教會 2026 讀經進度存在兩份版本：

- **惠君的 PDF**（39 頁，教會紙本）：7/20 雅各書 1+2 合併為一天。
- **Gemini 網頁版**：7/20 雅 1、7/21 雅 2 分兩天，改在 12/31 民 18+19 合併，兩版於 12/31 收斂回一致。

遊戲自始依網頁版建 SCHEDULE，因此 7/20 起遊戲進度比 PDF 慢一天。2026-08-30 已完整比對 PDF 全 39 頁（第 29–39 頁＝9/26–12/31），確認差異僅此一處位移。

## 決策

**遊戲維持網頁版進度，不改、不對齊 PDF。** 10–12 月進度依 PDF 換算（PDF 日期＋1 天）寫入 CLAUDE.md 全年進度表；之後不需再向 James 或教會索取進度。

## 取捨

- 對齊 PDF 等於把 7/20 以後所有日期整體前移一天，但 **SCHEDULE 日期已綁定玩家完成紀錄**（每章完成的 date、日曆補讀、B1 事件流都以日期為軸）——改日期會讓已完成玩家的日曆與統計錯位，實質不可逆。
- 不對齊的代價極小：玩家對照教會紙本最多差一天，12/31 自然收斂；牧師已明確表示按自己習慣即可。

## 後果

- 7/20–12/30 遊戲章節比 PDF 慢一天；12/31（民 18+19 合併日）兩版收斂一致。
- 10–12 月合併日 8 處（10/11 創47+48、10/23 出10+11、11/04 出23+24、11/16 出36+37、11/27 利8+9、12/09 利21+22、12/21 民7+8、12/31 民18+19）依此換算，正本在 CLAUDE.md。
- 未來教會若發新版進度，評估時以「日期綁玩家完成紀錄故不可逆」為前提，預設不追溯改動已過日期。
