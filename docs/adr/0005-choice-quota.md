# ADR 0005：情境題四格立場配額

- 日期：2026-08-30
- 狀態：已採納（James 拍板；軟性配額，執行正本＝CLAUDE.md「情境題設計原則」第 6 條）
- 關聯：memory `choice-quota-2026-08-30.md`；PR #52（創世記 2/4/6/8/11 情境題回補）；`content-tone-guide.md`

## 背景

GEN1–24 情境題審計發現：73% 的選項落在「軟弱－掙扎－受傷」光譜，其中六章四格都在同一條軸線、只差強度；玩家實際反映「四個都不像我」——最近過得還好、或已經在實踐的玩家沒有一格可選，與設計原則「四格必須是不同立場」的初衷背道而馳。

## 決策

自 2026-08-30 起，新寫章節適用軟性配額：

1. **軟弱－掙扎－受傷光譜至多兩格。**
2. **至少一格**留給「我已經在做了／這對我不難」或「這章我沒特別感覺」的玩家。
3. **「我不同意經文」格不開**——在雷區章開這格等於請玩家審判經文，違反語氣基調。
4. **已上線章節不追溯重寫**，最多換最弱的一格；首批回補＝創 2/4/6/8/11（PR #52，隨 2026.08.30 上線）。

## 取捨

- 不追溯的原因：`choiceSelected` 只存選項字母（A–D），日記以「當前選項文字」渲染——整批重寫舊章會讓玩家日記裡的歷史選擇對到不同的文字，扭曲玩家自己的紀錄。
- 因此**內容永久分成兩代**（配額前／配額後並存），此後果已知且接受，也是本決策難以回退的原因。

## 後果

- 配額是軟性原則、不是硬檢查：`validateContent` 不驗立場分布，靠生成 prompts（`claude-code-agent-prompts.md`）與審查流程把關。
- 之後的章節審計以「軟弱光譜 ≤2 格、必有『我還好』格」為驗收線。
