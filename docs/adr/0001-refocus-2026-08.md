# ADR 0001：2026-08 重新對焦——從「加內容」轉向「重新點燃」

- 日期：2026-08-24
- 狀態：已採納（James 於 Claude Code 對焦會談拍板）
- 相關研究：`docs/research-progression-visuals.md`（視覺成長業界做法）

## 背景

2026-05-30 戰略轉向「不追成長、重深度」之後，開發重心逐漸被每日內容生產佔滿。8/24 對焦時 James 直言：「連我自己玩都有點乏味無力」，希望找到方法幫自己與既有玩家**重新點燃靈修熱情**——這是本輪所有決策的量尺。

## 診斷：為什麼乏味

1. **流程可預期**——每天同樣的步驟循環，沒有變化感。
2. **內容同質**——章節之間感受不出差異。
3. **進度失去意義**——完成數字不再帶來前進感。

**不是孤獨感**（2026-08-27 **降回待驗證**：此判斷來源是 James 一人內省，證據等級不足以當全體診斷；8/28 儀式後對照「有回來 vs 沒回來」的 B1 軌跡補行為證據）。社交類功能暫留冰箱，門不上鎖。

## 決策

1. **受眾優先序**：James 本人＋週活躍核心（12-15 人）優先；流失玩家（約 100 人）優先度低——召回這張牌只能打一次，不用半成品去敲門。
2. **小點燃先行**：8/28「新約之旅・終點」一次性儀式（PR #17，已合併 dev）。顯示窗 8/28–9/06、個人段門檻 21 章、提摩太後書 4:7 收尾（已驗 CUNP1）。上正式版當天需重跑數據快照更新群體數字、GAME_VERSION 改當天日期。
3. **視覺成長三原則**（依研究報告，James 核可「業界怎樣我們有樣學樣」）：
   - **出席驅動**：視覺成長只綁「有沒有完成靈修」，絕不評默想品質或字數（過度辯證效應：對內在動機的行為附加外在評價會侵蝕動機本身；Finch 模式）。
   - **雙層節奏**：每日可感的微變化＋里程碑式大變身（Duolingo／Finch 通用配方）。
   - **累計成就不因 streak 中斷歸零**（YouVersion 做法：中斷懲罰只限連續類，累計類永久保留）。
4. **書架路線**：創世記直接接在新約後面（走到哪讀到哪），不做新舊約分區。
5. **教會進度綁定不變**：拓展其他教會、自訂進度都是以後的事。
6. **視野**：規劃到 2026 年底；2027 走向視教會下一年計畫再定。
7. **核心指標（James 2026-08-24 拍板，取代「北極星」）**：「北極星」一詞退役（單人維護沒有對齊團隊的需求，只剩溝通成本；依 `docs/research-north-star-metric.md`）。改為**一句白話核心句＋兩個守門數字**：
   - 核心句（2026-08-27 改雙層）：「**本週有幾個人完成靈修**」（任一章完成即算，對齊出席驅動）。
   - 守門 1：其中幾人寫了默想＋默想平均字數有沒有掉（防敷衍）。
   - 守門 2：連續 4 週沒出現的人名（12-15 人規模，認人比看曲線準）；曾完成 100+ 章者特別標記（只標示不召回）。
   - 閱讀方式：看月趨勢與人名清單，不當成長曲線讀（週波動無意義）。
   - 用途＝方向盤：評估新功能時問「這會讓更多人真的靈修嗎」。

## 2026-08-27 六角色評估拍板（正本＝`docs/history/role-review-decisions-2026-08.md`）

主菜定案與排程：
1. **PR ①（本週）文案批＋自我約定＋AI 看裝備**：🔥「連續」→「累積靈修 N 天」、成就改「累積 7/14/30 天」；分享去天數行、`first_share`／`share_10` 下架；「前往閱讀」旁加「我已經讀過這章了」（同 +15 XP，不驗證，口徑改「閱讀勳章領取率」）；「稀有裝備」→「默想裝備」；「明天大概什麼時候？」自我約定（可開關、只存 localStorage、不推播）；aiReflection prompt 帶入裝備 desc 經文（至多引一句、不合則不提，上線前 10 組失焦測試）；`npm run core` 雙層輸出＋100+ 章者標記。
2. **PR ②（8/28 儀式反應後）焦點模式**：日曆預設收合、選章後隱藏 avatar/XP/日曆、完成短畫面 2-3 秒（🔥當日出席燈＋當日裝備＋「📖 啟示錄 收集 7/44」）。（完成短畫面已於 8/29 併入領獎畫面，James 拍板）
3. **PR ③ 書卷詳情頁第二期**：裝備剪影＋卷徽章（疊書架封面灰→亮）、砍自動換裝→入袋＋試穿、稱號改綁完走卷數、每卷一件真稀有（完走才給）、完走儀式 AI 用該卷裝備＋情境答案寫 200 字旅程故事。（2026-08-29 ③c「每卷真稀有／每卷專屬稱號」砍：與 ③b 累計階梯重複；2026-08-30 ③d 完走儀式＋旅程故事擱置：pm-critic 冷評估）
4. **之後**：等級階梯（Lv.5 化身框／10 AI 回應風格／15 順序自選／20 旅程地圖／25 稱號自訂／30 AI 引用上一章默想／40 完走回顧卡，只解周邊不鎖靈修本體）；「試煉」實驗（AI 生成四選一遭遇，選項由裝備決定，鑰匙非數值）。

原則補充：補讀／提前**維持原樣不加獎懲**（減負擔設計）；真戰鬥系統不做；視覺主菜為紀錄型可過，9 月看每人每週章數是否回升驗證。
