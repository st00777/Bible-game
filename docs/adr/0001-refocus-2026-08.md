# ADR 0001：2026-08 重新對焦——從「加內容」轉向「重新點燃」

- 日期：2026-08-24
- 狀態：已採納（James 於 Claude Code 對焦會談拍板）
- 相關研究：`docs/research-progression-visuals.md`（視覺成長業界做法）

## 背景

2026-05-30 戰略轉向「不追成長、重深度」之後，開發重心逐漸被每日內容生產佔滿。8/24 對焦時 James 直言：「連我自己玩都有點乏味無力」，希望找到方法幫自己與既有玩家**重新點燃靈修熱情**——這是本輪所有決策的量尺。

## 診斷：為什麼乏味

1. **流程可預期**——每天同樣的步驟循環，沒有變化感。
2. **內容同質**——章節之間感受不出差異。
3. **進度失去意義**——完成數字不再帶來前進感。

**不是孤獨感**。因此社交類功能（小組排行榜、共讀、群體鏡像）判定不是解方向，降冰箱。

## 決策

1. **受眾優先序**：James 本人＋週活躍核心（12-15 人）優先；流失玩家（約 100 人）優先度低——召回這張牌只能打一次，不用半成品去敲門。
2. **小點燃先行**：8/28「新約之旅・終點」一次性儀式（PR #17，已合併 dev）。顯示窗 8/28–9/06、個人段門檻 21 章、提摩太後書 4:7 收尾（已驗 CUNP1）。上正式版當天需重跑數據快照更新群體數字、GAME_VERSION 改當天日期。
3. **視覺成長三原則**（依研究報告，James 核可「業界怎樣我們有樣學樣」）：
   - **出席驅動**：視覺成長只綁「有沒有完成靈修」，絕不評默想品質或字數（過度辯證效應：對內在動機的行為附加外在評價會侵蝕動機本身；Finch 模式）。
   - **雙層節奏**：每日可感的微變化＋里程碑式大變身（Duolingo／Finch 通用配方）。
   - **累計成就不因 streak 中斷歸零**（YouVersion 做法：中斷懲罰只限連續類，累計類永久保留）。
4. **書架路線**：創世記直接接在新約後面（走到哪讀到哪），不做新舊約分區。
5. **教會進度綁定不變**：拓展其他教會、自訂進度都是以後的事。
6. **視野**：規劃到 2026 年底；2027 走向視教會下一年計畫再定。
7. **核心指標（James 2026-08-24 拍板，取代「北極星」）**：「北極星」一詞退役（單人維護沒有對齊團隊的需求，只剩溝通成本；依 `docs/research-north-star-metric.md`）。改為**一句白話核心句＋兩個守門數字**：
   - 核心句：「**本週有幾個人完成靈修並寫下默想**」（取代 streak≥7×默想率×editDuration 複合式）。
   - 守門 1：默想平均字數有沒有掉（防敷衍）。
   - 守門 2：連續 4 週沒出現的人名（12-15 人規模，認人比看曲線準）。
   - 閱讀方式：看月趨勢與人名清單，不當成長曲線讀（週波動無意義）。
   - 用途＝方向盤：評估新功能時問「這會讓更多人真的靈修嗎」。
