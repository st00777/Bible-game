## 一、五條依據 → 五個結論

| 依據 | 結論 |
|---|---|
| 1 體驗 | 一句話：**「這條路有人陪我走，手裡有光。」** 角色是分身不是主角，不看鏡頭、不評價；小羊是純氛圍旅伴。錨圖要讓人第一眼感到「溫暖陪伴＋剛出發的期待」，不賣萌、不英雄、不宗教。 |
| 2 要重做的地方 | animation-map 第二節 12 時刻中真的要角色的只有 7 個：主畫面待機、出發舉燈、默想坐營火、每日完成（白天舉手／深夜抬燈）、成就（沿用舉手）、完走收卷、試穿小動作。另加行囊換皮與營地四時段背景。 |
| 3 不偏離現行風格 | 現行 UI＝淺天藍→米白漸層、圓角奶油卡片、深棕字。**錨圖改「清晨暖光」**：天空淡藍＋奶油黃光源，角色本身仍是暖色水粉（沙、紫、苔綠、赭）。黃昏／深夜留給時段背景，不當第一張錨。角色在 UI 上的落點用暖白暈圈（現有 `--card #FFFDF8`）當底，冷藍到暖角色的過渡讀成營火光暈。**畫風本身不為 UI 調亮或調冷。** |
| 4 Rive 適用形式 | **整張姿勢圖切換＋Rive 內微動畫**，不再切件綁骨（p2/p4 已證明零件互飄、ChatGPT 不保留原像素）。每張姿勢＝一張透明 PNG，角色高 600–700 px；呼吸與外袍微晃用 Rive mesh 微變形；眨眼用 Rive 向量眼皮（膚色形狀蓋眼睛）；油燈光暈、營火用 Rive 向量＋粒子；載入失敗備援＝待機 PNG。 |
| 5 Images 2.5 提示詞法 | 中文、分段「成品／角色一致性／固定畫風／本次只改變／禁止」；同一對話續生；每張重述臉／髮／衣／比例四要素；一次只改一件事；姿勢漸進（站→舉燈→坐），不要一次跳太遠；生完驗 alpha、疊圖比對。 |

## 二、錨圖規格（第一張，做到滿意前不生其他）
- **成品**：一張情緒定錨插畫，不是遊戲內背景。直式（手機）。
- **誰**：一位旅人＋一隻小羊在腳邊，同向望向路。先出一套性別（女版先，p4 已走通），男版之後照同比例續生。
- **場景**：草地小徑起點，遠方低矮丘陵與小路，零星營火記號。**清晨**偏暖柔光，天空淡藍。
- **鏡位**：3/4 側前方、視線水平、**全身**、小成人約 5.5–6 頭身。
- **服裝**：帽兜外袍（帽兜放下）＋沙色內袍＋側背包＋皮靴，手提亮著的小銅油燈。
- **不放**：狐狸（已退役）、武器盔甲、宗教符號、文字 Logo、Q 版大頭、動漫大眼或點眼、硬黑描邊、賽璐璐、3D、寫實。
- **驗收**：James 看了想把它當手機桌布；放到遊戲天藍底截圖旁不覺得是兩個世界；臉有眼白＋虹膜＋小鼻；頭身 ≥5.5。

## 四、順序與驗收點
1. **錨圖**（可能來回 3–5 次）：James 滿意才往下。
2. **定裝**（同對話）：臉同一人、頭身 ≥5.5、對稱、白底無影。
3. **idle → lamp_lift → raise_day**（同對話，漸進）：三張並排臉／髮／衣／比例同一人；貼到遊戲天藍底截圖旁看是否協調；驗 alpha；疊圖比對只有手臂區域不同。
4. 第一批過 → CC 做 Rive 待機（mesh 呼吸＋眼皮眨眼＋燈暈）小樣給 James 看，再進第二批。
5. 每批交付：`SendUserFile` 傳圖＋一行張數尺寸＋哪張要重生。

## 五、風險與預防
- **臉跨姿勢飄**：每張附錨圖＋上一張核可圖、重述四要素；姿勢漸進；對話斷掉先補一張定裝續生。
- **人羊比例脫節**：第一張羊一定與人同框；把「羊肩高＝人腰高」寫死重複用。
- **為配 UI 把水粉調亮而失去質感**：錨圖用清晨光是換「時段」不是換「畫風」；紙紋、暖棕描邊、低飽和不動。
- **ChatGPT 額度**：Plus 免費月 10/12 前取消；錨圖迭代可能吃掉一天額度，第一批分兩天。
