## 一、角色定位
1. **角色是玩家分身**：動作只反映「玩家正在做什麼」，從不看向玩家、不對玩家做任何評價性動作。
2. **小羊＝純氛圍旅伴**：沒有狀態、不記錄出席、不會餓／走／難過（Finch 式「無衰弱的等待」；排除 Duolingo／Forest 式愧疚機制）。P1 的狐狸退役（聖經意象負面）。
3. **性別三值、皮膚兩套**：先畫一套當定裝標準，第二套照同一張定裝圖比例出；同一套骨架、關節座標共用。皮膚在衣櫃自選、不綁性別欄位，預設第一套（ADR 0006）。

## 三、與現有畫面的合併
- **領獎畫面**（`showReward`）：`#reward-av` 的 emoji 小人位置換成 Rive 角色；「今天出席了」燈、裝備揭曉、試穿按鈕、分享文字、自我約定全不動。彩屑（`launchConfetti`）白天保留、深夜不呼叫，且深夜改觸發 `lampTrigger` 而非 `liftTrigger`。
- **書架頁**（📚 書卷與成就）：換皮成「行囊」——打開的行囊、卷軸一排插在袋裡，點卷軸翻開詳情。全文件統一用「行囊」，不用「背包」。資料、規則、事件埋點全不動，純視覺。完走動畫結尾卷徽章飛向分頁圖示。
- **成就解鎖畫面**（`ach-unlock-overlay`）：徽章彈跳保留，角色做舉手。

## 四、裝備與素材規則
- **外袍三族**：披風（無袖）、短衣、長袍。日常給披風與短衣；長袍留里程碑稀有款。有袖族每件自帶袖子零件（art-director 2026-09-07 裁定，不共用手臂）。
- **坐姿**：只畫三張族版（3/4 側面），同族不同色用 ImageMagick 離線改色相產圖；帽子與手持坐下時「放在旁邊」畫成固定行囊。Rive 即時染圖未查證、視為不支援，顏色版本一律預產圖檔。
- **舊裝備 424 件**：成為「紀念物」進行囊，可別一件當掛件（ADR 0006 取代原「舊物袋」）。
- **素材產線新開三批**：小羊（待機＋抬頭＋靠近）、坐姿三族側面、第二套性別皮膚。全部走 `bible-art-assets` 產線＋風格錨。

## 七、補漏（2026-09-09 James 同意）
- **載入備援**：Rive runtime 或 .riv 載入失敗（iOS Safari 首要）時顯示靜態角色 PNG；.riv 檔案大小預算由 CC 定並寫進 rive-rigging 驗收清單。
- **老玩家過場**：首次進入新版有一段過場——說明換了新形象、選身形、一次發放回溯換算的穿戴裝備（儀式感）。
- **掛件位置**：紀念物掛件只出現在行囊頁與主畫面角落的行囊圖示上（emoji），**不畫在角色身上**（風格衝突、產線撐不住）。
