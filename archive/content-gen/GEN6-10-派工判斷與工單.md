## 二、全批共通約束

### 經文來源（嚴標準，不可降級）

```
https://rcuv.hkbs.org.hk/CUNP1/創世記/{章}/
```

- **驗證方式：查頁面內嵌的站方版本識別區塊 `CUNP1|新標點和合本(神)`。**
- 🔴 **不得只驗 title、不得只驗 HTTP 200。** `/CUNP/`、`/CUNPSS/`、`/CUNP_1/` 三個錯誤路徑同樣回 HTTP 200，內容是和合本 2010（和修版），且 title 前半與正確路徑完全相同。無 404、無錯誤訊息。
- hkbs 的 title 模板會把全書卷名清單與簡稱清單用 `=` 串接，產生看似錯亂的字串（例：`…猶大書,啟示錄=創,出,利…`）。**這是模板缺陷，與版本無關，不必驚慌，但也不可用來當版本依據。**
- 🔴 **絕不從記憶寫經文。** 每一節落檔前先抓源、逐字比對。
- 每章附查證紀錄：抓取的 URL、識別區塊驗到的字串、所選節號的逐字原文。

### 落檔用字規範

| 項目 | 規範 |
|---|---|
| 逐字 | 原樣落檔，不改字、不改標點 |
| 異體字 | 「裏」一律改「裡」（唯一跨欄例外，本批須驗 `裏` = 0） |
| 敬空 | U+3000 移除 |
| 「甚麼」 | 照原文，不改寫成「什麼」 |
| 「着」「鈎」 | 照原文，屬既有房規，非錯字 |
| 同位語連接號 | 用 U+FF0D（全形連字號），照 hkbs 原字 |
| 「耶和華神」 | **不帶任何連接字元**（已 byte 層驗證，創 2 全章 11 處皆直接相連） |
| 破折號 | 非經文散文可用 U+2014，**必成對出現**。單一 U+2014 = 錯誤狀態。經文欄照原文 |
| U+2500 | 僅可出現於 `//` 註解分隔線，內容欄位一律禁用 |
| 稱神 | **非經文散文中第三人稱稱神一律用「祂」**，不用「他」。經文欄照原文保留「他」 |

### hkbs 三種標記處理

| 標記 | 性質 | 處理 |
|---|---|---|
| `<i>` | 專名斜體（人名、地名） | **屬正文，保留文字** |
| `<ins>` | 小字補字（原文無、中文語法需要） | **屬正文，保留文字** |
| `<sup>` | 譯註（或譯／原文是／有古卷是） | **須剝除** |

判準：拿掉之後句子是否仍完整。`<ins>` 拿掉會殘缺（剝除即漏字，屬語意層錯誤）；`<sup>` 拿掉不影響。

### 選節紀律

金句卡與裝備 desc 是**單節獨立呈現**。除內容合適外，每一節須額外通過：

| 檢查項 | 不通過的處理 |
|---|---|
| 句末是否為句號／驚嘆號／問號 | 逗號、頓號、分號結尾 → **換節或擴節** |
| 引號是否在該節內閉合 | 未閉合或孤立閉引號 → **換節或擴節** |
| 是否為跨節括號插入語 | 開括號在前節 → **換節或擴節** |
| 是否帶 `<sup>` | **主動列出**（資訊，非缺失） |

🔴 **標點不完整時，作法是換節或擴節，絕不改標點。**

前四批換節統計：9A 換 6 節、9B 換 5 節、9C 換 6 節、GEN1-5 換 2 節。換節是常態，不是異常。

**本批預期高換節章**：創 10（族譜體，多為名單句與分號連接）、創 7（多處日數與清單句）。

### 裝備命名紀律

🔴 **只取該節既有詞語，不得添加經文沒有的意象。**

這是 P0 修正的核心教訓：ROM4 base 原寫「你的後裔將要如此——如天上的星那樣多」，後半是從創 15:5 混進來的，羅 4:18 沒有這句話。

- 裝備名的用詞須出自 `desc` 所引節之內。
- 經文引用不可跨章：`baseItem.desc` / `bonusItem.desc` 所引節須與該 chapter key 同章。
- 同章的 base 與 bonus 不共用同一節。

### 提前靈修：每章出口必須自足

日曆有「提前靈修」路徑，玩家可一次讀完創 6-10 五章。
🔴 **每一章的出口必須在該章之內成立，不得倚賴「明天會讀到安慰」。**
（判準 2，content-tone-guide.md 創世記段落）

四章連讀為「毀滅 → 關門 → 記念 → 立約」的完整弧線，但四個出口各自獨立。
