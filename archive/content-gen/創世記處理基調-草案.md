## 零、為什麼創世記需要另一套基調

啟示錄的難處是**內容太重**（審判、災難、火湖）。
創世記的難處不同，是**結構完全不一樣**，而且雷區的性質更貼身。

三個結構性差異：

| | 啟示錄 | 創世記 |
|---|---|---|
| 文體 | 書信 + 異象 | 敘事 |
| 對讀者說話的結構 | 有（主對七教會說、約翰對讀者說） | **無**（故事本身不對讀者說話） |
| 雷區性質 | 對未來的恐懼（審判、災難） | 對自己處境的解釋（咒詛、被棄、失去） |

第三項最關鍵。啟示錄的雷區是「將來會不會發生在我身上」，
創世記的雷區是「**現在發生在我身上的事，是不是因為這個**」——
生產之苦、終身勞苦、不被看中、被逐出家門、失去孩子。

**這些不是想像中的恐懼，是玩家可能正在經歷的事。**

## 一、核心判準（三條）

### 判準 1：不把經文變成對玩家處境的解釋

創世記記載了苦難的來源（創 3），但**記載來源不等於解釋每一個個案**。

- ❌ 不可暗示：你的難產、你的工作辛苦、你的家庭破裂，是因為創 3 的咒詛
- ❌ 不可暗示：你的禱告不蒙悅納，是因為你像該隱
- ❌ 不可暗示：你失去的，是神在試驗你像試驗亞伯拉罕
- ✅ 可以說：這段經文記下了世界為什麼會有這些難處
- ✅ 可以說：神在這件事裡怎麼對待當事人

**判準句**：這一章如果讀給一個正在經歷同樣處境的人聽，
他會不會覺得經文在說「這是你活該」或「這是神安排來磨你的」？
會的話，處理方式錯了。

### 判準 2：沉重段落必須自足（PM 2026-08-01 加入）

**每一個雷區章的出口都要在該章之內完成**，不得倚賴
「明天會讀到安慰」「下一章會轉折」。

原因：日曆有「提前靈修」路徑，玩家可以一次讀完數章。
創世記首批 GEN1-10 尤其密集——創 3 墮落、創 4 該隱、
創 6-9 洪水，中間只隔一章創 5 家譜，而創 5 本身重複八次
「他就死了」，那章的節奏也是沉重的。

**判準句**：把這一章單獨抽出來，給一個正在難處中的玩家讀，
他讀完是否有地方可以站？

### 判準 3：不裁定經文沒有裁定的事

沿用 9B 的 REV12 手法（PM 認可為新的好做法）：
承認解釋分歧本身就是誠實，不需替玩家決定。

創世記需要套用此判準的高頻處：
- 創 1 的「日」是多長（六日創造的時間跨度）
- 創 4 神為何看中亞伯不看中該隱（經文未說明）
- 創 6:2「神的兒子們」所指為何
- 創 6-9 洪水的範圍（全球或局部）
- 創 22 神為何要如此試驗亞伯拉罕

**寫法**：「這一點歷來有不同的理解」，然後把重心放在經文確實說了的事。

## 二、敘事體如何出情境題（全新手法）

書信體的情境題很直接：作者對讀者說了一句話，情境題問玩家「你面對這句話時比較靠近哪一種」。

**敘事沒有這個結構。** 故事在講別人的事，玩家是旁觀者。
硬把敘事轉成訓誡，就會變成「你要像亞伯拉罕一樣有信心」——
那正是我們要避免的說教。

### 三種可用的提煉路徑

#### 路徑 A：情緒對位（首選）

不問玩家「你會不會這樣做」，問「你有沒有過同樣的感受」。

> 創 4 該隱：不問「你會不會嫉妒」，
> 問「你有沒有過那種——別人被看見了，你沒有，的感覺」

> 創 16 夏甲：不問「你會不會逃跑」，
> 問「你有沒有過覺得自己在一個地方是多餘的」

情緒是共通的，行為不是。玩家不會殺弟弟，但每個人都嘗過不被看中。

#### 路徑 B：神的動作（次選）

把焦點從人物移到神身上——經文裡神做了什麼、說了什麼。

> 創 3：神為亞當夏娃做皮衣（3:21）——在宣告咒詛之後，
> 祂親手為他們做衣服。情境題可以問「你有沒有在最不堪的時候，
> 被誰不聲不響地遮蓋過」

> 創 16：神找到曠野中的夏甲，問她「你從哪裡來，要往哪裡去」
> （16:8），夏甲稱祂「看顧人的神」。情境題方向：被看見

這條路徑特別適合人物行為不堪的章節（創 9 挪亞醉酒、創 12 亞伯蘭
說謊、創 19 羅得），因為焦點不在人的表現。

#### 路徑 C：處境提問（備用）

當前兩者都不適用時，用故事裡的處境當開場，但不要求玩家評價人物。

> 創 6 洪水：不問「你覺得神這樣做對嗎」，
> 問「你有沒有看過一件事壞到你覺得沒救了」

### ❌ 禁用路徑

| 禁用 | 為什麼 |
|---|---|
| 「你要像 X 一樣」 | 說教，且把聖經人物當道德榜樣是誤讀（他們多半劣跡斑斑） |
| 「如果你是 X，你會怎麼做」 | 要求玩家評價經文人物，容易滑向自我審判 |
| 「X 錯在哪裡」 | 把靈修變成道德判斷練習 |

## 三、首批（GEN1-10）逐章雷區

### 創 1｜創造

| 項目 | 處理 |
|---|---|
| 雷區 | 無雷區，但有**裁定誘惑**：六日的「日」是多長、與科學的關係 |
| 處理 | 判準 3——不裁定，寫「歷來有不同理解」。重心放在「神看著是好的」與人是照神形像造的 |
| 情境題方向 | 你有沒有一部分的自己，是你不覺得「甚好」的 |

### 創 2｜伊甸園與造女人

| 項目 | 處理 |
|---|---|
| 雷區 | **2:18「那人獨居不好」** — 對單身、喪偶、離婚、或婚姻中感到孤單的玩家會刺。經文說「獨居不好」，一個獨居的人讀到，等同被告知「你現在的狀態不好」。教會場域對單身者的壓力本來就真實存在 |
| 處理 | 忠實呈現。但焦點放在**神看見那人的孤單，並且採取行動**——重點是神注意到了、神在意，不是「你該有個伴」 |
| ❌ 禁止方向 | 「你身邊有沒有一個人是神給的」這類問法，會讓沒有的人讀成缺損 |
| 情境題方向 | 你有沒有一種孤單，是你以為沒人注意到的 |
| 備註 | 創 2 同時是**創 3 咒詛的對照組**——這裡才是神設計的理想（骨中的骨、肉中的肉），創 3 是壞掉之後的現況。兩章要一起讀才不會誤解 |

### 創 3｜墮落與咒詛 — 首批最重

| 項目 | 處理 |
|---|---|
| 雷區 A | **3:16 生產之苦、戀慕丈夫、丈夫必管轄你** — 對經歷難產、不孕、婚姻困難的玩家，極易讀成「這是女人該受的」；「管轄」一句在教會場域是活的問題，會被讀成「神規定丈夫要管轄妻子」，婚姻中被壓制者讀到會覺得經文在說「這是應該的」 |
| 雷區 B | **3:17-19 終身勞苦、汗流滿面** — 易讀成「你的工作辛苦是活該」 |
| ★ 核心框架 | **3:16-19 描述的是關係破裂後的「現況」，不是神設計的「理想」。** 創 2 才是理想（骨中的骨、肉中的肉）。咒詛在描述世界壞掉之後變成什麼樣子，不是在規定它應該是什麼樣子。導讀須明寫此框架 |
| 框架適用性 | 此框架同時解掉 3:16 與 3:17-19——沒有人會說「終身勞苦是神規定工作應該痛苦」，同樣邏輯適用於 3:16 的管轄 |
| 處理 | 導讀忠實呈現全部咒詛，不軟化。但須明寫：**這是在說世界為什麼變成這樣，不是在說你個人的遭遇是懲罰** |
| 出口 | **3:21 神為他們做皮衣給他們穿** — 這是全章的落腳點。宣告咒詛之後，神親手為他們遮蓋。路徑 B |
| 情境題 | 錨定 3:21。方向：你有沒有在最狼狽、最想躲起來的時候，被誰安靜地遮蓋過 |
| ❌ 絕對禁止 | 任何把玩家的具體苦難連結到咒詛的措辭 |

### 創 4｜該隱與亞伯

| 項目 | 處理 |
|---|---|
| 雷區 A | **4:4-5 神看中亞伯不看中該隱，經文未說明原因** — 易生「神偏心」「我做的神也不喜歡」 |
| 雷區 B | 4:8 殺弟 |
| 處理 A | 判準 3——經文沒說原因就不編造原因。不可說「因為該隱獻的不是最好的」（經文未如此說）。可寫「經文沒有解釋為什麼」 |
| 處理 B | 忠實呈現，情境題不碰殺人本身 |
| 出口 | **4:6-7 神主動來問該隱「你為什麼發怒」** — 神沒有先定罪，先問。還有 4:15 神給該隱記號保護他 |
| 情境題 | 路徑 A 情緒對位。方向：你有沒有過那種——別人被看見了，你沒有 |
| ⚠️ 特別注意 | 「你的禱告神不聽是因為你有問題」是這章最容易滑出去的方向，絕對避免 |

### 創 5｜家譜

| 項目 | 處理 |
|---|---|
| 表面 | 家譜，看似無雷區 |
| 實際 | **「他就死了」重複八次**，那章的節奏本身是沉重的。不是喘息章 |
| 出口 | **5:24 以諾與神同行，神將他取去** — 名單裡唯一沒有「他就死了」的一個 |
| 情境題 | 方向：日子一天天過去，你有沒有一件想跟神一起做到底的事 |
| 備註 | 這章可以做得很好——長長的名單裡突然有一個人不一樣，那個對比本身就是信息 |

### 創 6-9｜洪水 — 與啟示錄審判同級

| 項目 | 處理 |
|---|---|
| 雷區 A | **全人類毀滅**（7:21-23）。這是全本聖經中最大規模的審判之一 |
| 雷區 B | **6:6 神心中憂傷** — 不可用來暗示「你也讓神憂傷」 |
| 雷區 C | **9:20-25 挪亞醉酒、咒詛迦南** — 人物劣跡，且咒詛的對象是孫子，歷來被誤用 |
| 雷區 D | **6:1-4「神的兒子們」與偉人** — 套判準 3。墮落天使說／塞特後裔說／王族說，歷來有不同理解，**不裁定**。導讀寫「這幾節歷來有不同的理解」即可，**不往靈異或神祕學方向發展**，不展開任何一說的細節 |
| 處理 A | 忠實呈現，不軟化毀滅的規模。但情境題不讓玩家站在「將被毀滅」的位置（同啟示錄條 2） |
| 處理 B | 6:6 呈現，但框架是「神不是無動於衷的神」，不是「你讓神難過」 |
| 處理 C | 忠實呈現挪亞的失敗。判準 3：迦南被咒詛的原因歷來有不同理解，不裁定。**絕不可用於任何族群的當代影射** |
| 出口分布（判準 2） | 創 6：**6:8 挪亞在耶和華眼前蒙恩**／創 7：**7:16 耶和華把他關在方舟裡面**（神親手關門）／創 8：**8:1 神記念挪亞**／創 9：**9:13 虹為記號** |
| 情境題方向 | 創 6：你有沒有看過一件事壞到你覺得沒救了／創 7：被關在裡面（保護與困住的一體兩面）／創 8：神記念（你有沒有覺得被忘記過）／創 9：記號（神主動立約，不要求人先做什麼） |
| ⚠️ 四章連讀 | 若玩家一次讀完 6-9，那是「毀滅 → 關門 → 記念 → 立約」的完整弧線。四個出口各自獨立，符合判準 2 |

### 創 10｜列國表

| 項目 | 處理 |
|---|---|
| 雷區 | 無。但內容為名單，難以做出情境題 |
| 處理 | 重心放在「各隨他們的宗族、方言、邦國」——神的心意從一開始就涵蓋萬族 |
| 情境題方向 | 路徑 C。方向：這份名單裡沒有一個你認識的名字，但神都記下來了——你有沒有覺得自己太渺小、不值得被記住 |
| 合併日 | 9/06 為創 9+10 合併日，兩章各自完整生成 |

## 四、全卷其他高風險段落（首批之後，先行標記）

| 章 | 雷區 | 預定處理方向 |
|---|---|---|
| 創 12:10-20 | 亞伯蘭謊稱撒萊是妹妹 | 路徑 B——焦點在神仍保守，不在人的失敗 |
| 創 16 / 21 | 夏甲被逐 | 受害者敘事。出口為 16:13「看顧人的神」、21:17 神聽見童子的聲音。情境題路徑 A：被當作多餘 |
| 創 19 | 所多瑪 | **當代最易政治化的段落。** 不做任何當代影射、不裁定罪名的現代對應。焦點放在 19:16「耶和華憐恤羅得，拉著他的手」 |
| 創 19:30-38 | 羅得女兒 | 忠實呈現，情境題完全不碰 |
| 創 22 | 獻以撒 | **對有孩子的玩家衝擊極大，且有一個反向風險必須處理：以撒活下來了，但有些玩家的孩子沒有。** 教會裡有流產、有失去孩子的父母，創 22 剛好是他們最不該讀到「神會攔住」的地方——「神必預備」會被讀成「那為什麼沒有為我預備」。導讀忠實呈現。情境題絕不可問「你願不願意把最愛的交出來」，**也不可錨在 22:12「神在動手前攔住」或 22:14「耶和華必預備」的結果面**。★ 改錨 **22:8「神必自己預備」**——那是亞伯拉罕在還不知道結果時說的話。焦點是「在不知道結局的路上還走著」，不是「結局一定是好的」。情境題方向：你有沒有一段路，是你不知道結果、但還是走下去了。此處理既忠實原文，又不承諾玩家一個神沒有承諾的結局 |
| 創 34 | 底拿 | 性暴力敘事。忠實呈現，情境題不碰 |
| 創 37-50 | 約瑟 | 相對安全，但 50:20「你們的意思是要害我，神的意思原是好的」不可用於為任何當下的傷害開脫 |
