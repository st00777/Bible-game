## 一、本批的結構性難處

### 難處 A：這是全卷最重的四章，接著是全卷最亮的兩章

| 章 | 性質 |
|---|---|
| 17-18 | 巴比倫大城的審判與傾倒 |
| 19 | 獸與假先知被扔進火湖 |
| 20 | **白色大寶座審判、死亡和陰間被扔在火湖裡** |
| 21-22 | 新天新地、不再有眼淚、生命水的河 |

**一批之內從火湖走到新耶路撒冷，落差是三批中最大的。**

### 難處 B：提前靈修路徑（本批最關鍵的設計前提）

日曆有「提前靈修」分支，內容一上 main 玩家當天即可讀完全部。
實際情形可能是：玩家從 9B 的第八章號筒，一路讀到本批第二十章的火湖，
**十三章不間斷的審判序列**。

**因此本批的核心設計要求：**

> **17、18、19、20 四章必須各自有獨立的出口，不得倚賴 21-22 的新天新地來平衡。**

判準句：把這一章單獨抽出來，給一個剛讀完十二章審判的玩家，
他讀完是否有地方可以站？

各章指定出口見第三節，**這些出口是本批的骨架，不可自行更換**。
若某章的出口經驗證後標點不可用，停下回報，由內容視窗換節，不要自行改錨。

### 難處 C：20 章是全卷最重的一章

火湖與白色大寶座同章。基調條 5 明訂：
**導讀忠實呈現，情境題不碰，轉向「名字記在生命冊上」的確據面。**

本批對此章的要求比條 5 更嚴：因為玩家可能是讀完十二章審判才到這裡，
他需要的不只是「轉向」，是一個明確的落腳點。

## 二、經文來源紀律

### 🔴 唯一正確來源（2026-08-01 更新）

```
https://rcuv.hkbs.org.hk/CUNP1/REV/{章}/
```

**`/CUNP/` 與 `/CUNPSS/` 皆回 HTTP 200，但內容是和合本2010（和修版），不是新標點和合本。**
這是靜默失敗——無 404、無錯誤，內容看起來完全正常。

**強制查驗**：抓取後須確認頁面 title 為「新標點和合本(神)」，
**不可只看 HTTP 200**。交付時須回報實際使用的 URL 路徑與 title 查驗結果。

### 落檔處理

1. 逐節原樣落檔，不改字、不改標點、不自行正規化
2. **例外**：「裏」一律改「裡」（異體字正規化，經文與非經文皆適用）
3. 敬空（神字前全形空格 U+3000）移除
4. **小字註不是正文**——`<sup title="...">` 內文字一律不得採用

### ★ 選節檢查（9A 換 6 節、9B 換 5 節，本批強制執行）

啟示錄為話語體，引號密度高。**每個選節落檔後，CC 必須逐節檢查並回報：**

| 檢查項 | 不通過的處理 |
|---|---|
| 句末是否為句號／驚嘆號／問號 | 逗號、頓號、分號結尾 → 停下回報 |
| 引號是否在該節內閉合 | 開引號未閉合、或孤立閉引號 → 停下回報 |
| **是否為跨節括號插入語** | 開括號在前節、閉括號在本節 → 停下回報（16:15 前例） |
| **該節是否帶小字註** | 一律主動列出，供內容視窗核對（不是缺失，是資訊） |

已知結構性陷阱（前兩批累積）：
- 天上大聲說的話常跨數節（12:10-12 前例）
- 詩歌體段落常以逗號分行
- 頌讚句可能是引語的收尾，帶孤立閉引號

### 字元規範

| 項目 | 規範 |
|---|---|
| 破折號 | 非經文區雙 `——`(U+2014×2)；**單一 U+2014 = 0**（單一即為同位語誤處理） |
| U+FF0D | 非經文欄禁用；經文欄照 hkbs 原文保留（「主神－全能者」型） |
| U+2500 | 內容欄 0（程式註解區的分隔線不計） |
| 欄位歸屬 | 位於「」內且逐字引自和合本 → 經文欄；引號外自寫文字 → 非經文欄 |

## 四、格式規範（比照 9A / 9B）

每章需齊備：

```
chapter / sceneEmoji / readTime
guide{ intro, outline[3-4 條], focus }
verse / verseRef / scene / q
choices[A,B,C,D] / responses{A,B,C,D}
reflectionTitle / reflection
baseItem{emoji,name,desc,slot} / bonusItem{同}
```

| 項目 | 規範 |
|---|---|
| outline 條數 | 3-4 條，範圍**連續無缺口**、涵蓋全章 |
| outline 內容 | 每條須涵蓋該範圍**全部重點**，不得只摘安全的一半（約一 5:16 判準） |
| ✦ | 每章恰 1 個，須標在 focus 實際聚焦的那一條 |
| choices | 四選項涵蓋不同信仰成熟度；**D 一律保留「我不確定／做不到」的出口** |
| responses | 每條結尾收在「情緒有重量的小步」——真人說得出口的一句話 |
| reflection | 每章恰 1 個 `\n\n` 分段 |
| 三節不共節 | verse / base / bonus 不得引用同一節；皆限本章內、**不跨章** |
| 稱謂 | 非經文稱神「祂」、禱告「祢」、獸「牠」；**經文原文的「他/你」照留** |
| 用字 | 「裡」不用「裏」；新增區塊 `裏 = 0` |
| 標點 | 經文欄保留原文標點；非經文區不得出現頓號 |
| readTime | 3-6 分鐘 |
| emoji | 新裝備 emoji×slot 須對全檔既有＋批內查重 |

## 五、全批通用禁止事項
