## 一、經文來源紀律（最重要）

**本規格只給節號與選節理由，一律不給經文原文。**

CC 落檔時必須：

1. 逐節抓 `https://rcuv.hkbs.org.hk/CUNP1/REV/{章}/`（新標點和合本．神版）
2. 原樣落檔，不改字、不改標點、不自行正規化
3. **例外**：「裏」一律改「裡」（專案既定慣例，異體字正規化）
4. 敬空（神字前全形空格 U+3000）移除
5. 破折號：經文內單 `—`(U+2014)；非經文區雙 `——`(U+2014×2)。禁用 U+2500、U+FF0D

內容視窗事後獨立抓 hkbs 逐字覆核，**不採 CC 自報**。

## 三、逐章規格

### REV1｜8/09｜人子異象

| 項目 | 內容 |
|---|---|
| 章旨 | 約翰在拔摩海島得啟示；七燈臺中人子的異象；約翰仆倒，主說「不要懼怕」 |
| outline 建議 | 1-3 節（讀這書的有福）／4-8 節（問安、阿拉法俄梅戛）／9-16 節（人子異象）／17-20 節（不要懼怕 ✦） |
| 雷區 | **1:12-16 人子異象威嚴度高**（眼目如火焰、腳像光明銅、面貌如烈日），約翰仆倒如死。可能讓人覺得神可怕 |
| 雷區處理 | 異象照呈現不軟化。但導讀須讓 1:17「他用右手按著我」與異象**同段呈現**，不可讓威嚴獨立成段而安慰落在別處 |
| 情境題方向 | 主動靠近的手。方向：你心裡的神是遠的、可怕的，還是會伸手按著你的？ |
| 選節建議 | verse **1:17**（不要懼怕＋右手按著）／base **1:18**（拿著死亡和陰間的鑰匙）／bonus **1:8**（阿拉法俄梅戛） |
| 備註 | 1:17 若整節過長，改用 1:17 後半不可行（禁截斷），改 verse 為 1:8、base 為 1:17 |

### REV2｜8/10｜四教會（以弗所、士每拿、別迦摩、推雅推喇）

| 項目 | 內容 |
|---|---|
| 章旨 | 主寫信給四個教會，各有稱讚與責備 |
| outline 建議 | 1-7 節（以弗所：離棄起初愛心）／8-11 節（士每拿：受苦不用怕）／12-17 節（別迦摩：住在撒但座位之處仍持守）／18-29 節（推雅推喇：容讓耶洗別 ✦ 位置見下） |
| 雷區 A | **2:4-5「你把起初的愛心離棄了…把你的燈臺從原處挪去」** — 自責型雷區，與老底嘉同型 |
| 雷區 B | **2:22-23「我又要叫她的兒女死」** — 全章最重 |
| 雷區處理 | 兩處皆導讀照呈現、不軟化。**2:22-23 須明寫對象是耶洗別與跟從她的人，不是收信的教會整體**。情境題完全不碰這兩處 |
| 通用判準 | 套用條 8：會擔心自己愛心變冷的玩家，這份擔心本身就是還在意的證據 |
| 情境題方向 | **條 3 指定框架：「主認識你的行為」** — 祂看見的不只是缺點，也包括你撐住的部分。方向：你覺得自己在信仰上退步了嗎？主怎麼看你這段時間 |
| 選節建議 | verse **2:19**（我知道你的行為…末後所行的比起初更多）／base **2:10**（至死忠心、生命的冠冕）／bonus **2:7**（生命樹的果子） |
| ✦ 位置 | 2:19 在 18-29 節段，✦ 標該段 |
| 備註 | verse 選 2:19 是刻意的——七封信中唯一稱讚「後來比起初更好」的一封，直接對沖 2:4「離棄起初的愛心」的自責感 |

### REV3｜8/11｜三教會（撒狄、非拉鐵非、老底嘉）— 本批最重章

| 項目 | 內容 |
|---|---|
| 章旨 | 撒狄按名活實則死；非拉鐵非略有一點力量卻蒙開門；老底嘉不冷不熱 |
| outline 建議 | 1-6 節（撒狄：要儆醒、白衣、生命冊）／7-13 節（非拉鐵非：敞開的門）／14-18 節（老底嘉：不冷不熱、勸買眼藥）／19-22 節（我所疼愛的我就責備、站在門外叩門 ✦） |
| 雷區 A | **3:15-16 老底嘉溫水** — 全卷對本遊戲玩家殺傷力最強（條 8） |
| 雷區 B | **3:1「按名你是活的，其實是死的」** — 自責型雷區，強度僅次於溫水 |
| 雷區 C | **3:5「必不從生命冊上塗抹他的名」**（條 9） |
| 處理 A | 導讀照呈現不改字。**情境題絕不可讓玩家自我判定為「溫水」**。出口用 3:19-20：責備的前提是疼愛，主是站在門外叩門不是甩門 |
| 處理 B | 同上，套用條 8 通用判準。導讀不可加任何「你是不是也這樣」的引導語 |
| 處理 C | **只呈現應許面。嚴禁作「所以有可能被塗抹」的反面推論**，導讀不得出現任何暗示可能被塗抹的措辭 |
| 情境題方向 | **條 8 指定：「願不願意開門」，不是「合不合格」**。方向：如果主此刻站在門外敲門，你會怎麼回應 |
| 選節建議 | verse **3:20**（我站在門外叩門）／base **3:8**（你略有一點力量…敞開的門）／bonus **3:5**（生命冊，應許面） |
| 備註 | 三節全取安慰面是刻意的：本章導讀承擔全部責備，裝備與金句不再加壓。3:8「略有一點力量」是給覺得自己不夠的人最直接的一節 |

## 四、格式規範（比照批次8）

每章需齊備：

```
chapter / sceneEmoji / readTime
guide{ intro, outline[3-4 條], focus }
verse / verseRef / scene / q
choices[A,B,C,D] / responses{A,B,C,D}
reflectionTitle / reflection
baseItem{emoji,name,desc,slot} / bonusItem{同}
```

硬性要求：

| 項目 | 規範 |
|---|---|
| outline 條數 | 3-4 條，範圍須連續無缺口、涵蓋全章 |
| ✦ | 每章恰 1 個，須標在 focus 實際聚焦的那一條 |
| choices | 四選項涵蓋不同信仰成熟度；**D 一律保留「我不確定／做不到」的出口** |
| responses | 每條結尾收在「情緒有重量的小步」——真人說得出口的一句話，不是「想一想」 |
| reflection | 每章恰 1 個 `\n\n` 分段 |
| 三節不共節 | verse / base / bonus 三者不得引用同一節；皆限本章內、不跨章 |
| 稱謂 | 非經文稱神一律「祂」、禱告第二人稱「祢」；**經文原文的「他」照留** |
| 用字 | 「裡」不用「裏」，經文亦然；新增區塊 `裏 = 0` |
| 標點 | 經文欄保留原文標點（含頓號）；非經文區不得出現頓號 |
| readTime | 3-6 分鐘，依章長合理配置 |

## 六、內容視窗審查重點預告

本批審查會特別盯：

- REV3 三個雷區是否各自照規格處理，尤其 3:5 有無出現反面推論
- REV6 情境題是否確實沒有碰 6:16-17
- REV2 的 2:22-23 對象是否明確切分
- 七教會的責備在導讀中是否被軟化或刪減（迴避不是選項）
- 全批七章語氣線是否連貫：不要懼怕（1）→ 不要哭（5）→ 擦去眼淚（7）
