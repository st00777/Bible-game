## 一、本批的性質：與啟示錄完全不同的難處

啟示錄的難處是**內容太重**。創世記的難處是**結構不同，且雷區更貼身**。

| | 啟示錄 | 創世記 |
|---|---|---|
| 文體 | 書信 + 異象 | **敘事** |
| 對讀者說話的結構 | 有 | **無**（故事不對讀者說話） |
| 雷區性質 | 對未來的恐懼 | **對自己現在處境的解釋** |

第三項最關鍵。啟示錄的雷區是「將來會不會發生在我身上」，
創世記是「**我現在經歷的事，是不是因為這個**」——
生產之苦、終身勞苦、不被看中。**這些是玩家可能正在經歷的事。**

## 二、三條核心判準（每章都要通過）

### 判準 1：不把經文變成對玩家處境的解釋

創世記記載了苦難的來源（創 3），但**記載來源不等於解釋每一個個案**。

| ❌ 禁止 | ✅ 可以 |
|---|---|
| 暗示你的難產／工作辛苦／家庭破裂是因創 3 的咒詛 | 說這段記下了世界為什麼會有這些難處 |
| 暗示你的禱告不蒙悅納是因為你像該隱 | 說神在這件事裡怎麼對待當事人 |

**判準句**：這一章讀給一個正在經歷同樣處境的人聽，
他會不會覺得經文在說「這是你活該」或「神安排來磨你的」？會的話就錯了。

### 判準 2：沉重段落必須自足

**每一章的出口都要在該章之內完成**，不得倚賴「明天會讀到安慰」。

原因：日曆有「提前靈修」路徑，玩家可一次讀完數章。
創 3 墮落、創 4 該隱連著，中間只有創 5 家譜——而創 5 重複八次「他就死了」，本身也是沉重的。

**判準句**：把這一章單獨抽出來給一個正在難處中的玩家讀，他讀完是否有地方可以站？

各章指定出口見第四節，**這些出口是本批的骨架，不可自行更換**。

### 判準 3：不裁定經文沒有裁定的事

沿用啟示錄 REV12 手法（PM 認可）：承認解釋分歧本身就是誠實。

本批需套用處：
- 創 1 六日的「日」是多長、與科學的關係
- 創 4 神為何看中亞伯不看中該隱（**經文未說明**）

**寫法**：「這一點歷來有不同的理解」，然後把重心放在經文確實說了的事。

## 三、敘事體情境題三路徑（全新手法，本批驗證）

書信體的情境題很直接：作者說了一句話，問玩家怎麼面對。
**敘事沒有這個結構**，故事在講別人的事，玩家是旁觀者。
硬把敘事轉成訓誡，就會變成「你要像亞伯拉罕一樣有信心」——那正是要避免的說教。

### 路徑 A：情緒對位（首選）

不問「你會不會這樣做」，問「**你有沒有過同樣的感受**」。

> 創 4 該隱：不問「你會不會嫉妒」，
> 問「你有沒有過那種——別人被看見了，你沒有，的感覺」

**情緒是共通的，行為不是。** 玩家不會殺弟弟，但每個人都嘗過不被看中。

### 路徑 B：神的動作（次選）

焦點從人物移到神——經文裡神做了什麼、說了什麼。

> 創 3：神為亞當夏娃做皮衣（3:21）。情境題問
> 「你有沒有在最不堪的時候，被誰不聲不響地遮蓋過」

特別適合人物行為不堪的章節。

### 路徑 C：處境提問（備用）

用故事裡的處境當開場，但**不要求玩家評價人物**。

### ❌ 禁用路徑

| 禁用 | 為什麼 |
|---|---|
| 「你要像 X 一樣」 | 說教；把聖經人物當道德榜樣是誤讀（他們多半劣跡斑斑） |
| 「如果你是 X，你會怎麼做」 | 要求評價經文人物，易滑向自我審判 |
| 「X 錯在哪裡」 | 把靈修變成道德判斷練習 |

### GEN2｜8/30｜伊甸園與造女人

| 項目 | 內容 |
|---|---|
| 章旨 | 神安息；造人於伊甸園；那人獨居不好，神為他造配偶 |
| outline 建議 | 1-3 節（第七日安息，神賜福給這日）／4-14 節（造人、伊甸園、四道河）／15-17 節（修理看守，分別善惡樹的吩咐）／18-25 節（那人獨居不好，骨中的骨 ✦） |
| **本章出口** | **2:18 神看見那人的孤單，並且採取行動** |
| 雷區 | **2:18「那人獨居不好」** — 對單身、喪偶、離婚、或婚姻中感到孤單的玩家會刺。經文說「獨居不好」，一個獨居的人讀到，等同被告知「你現在的狀態不好」。教會場域對單身者的壓力本來就真實存在 |
| 處理 | 忠實呈現。焦點放在**神看見那人的孤單，並且採取行動**——重點是神注意到了、神在意，**不是「你該有個伴」** |
| ❌ 禁止方向 | 「你身邊有沒有一個人是神給的」這類問法，會讓沒有的人讀成缺損 |
| 情境題方向 | **路徑 B**。方向：你有沒有一種孤單，是你以為沒人注意到的 |
| ★ 結構提醒 | 創 2 是**創 3 咒詛的對照組**——這裡才是神設計的理想（骨中的骨、肉中的肉），創 3 是壞掉之後的現況。intro 須埋下這個對照，供次日 GEN3 使用 |
| 選節建議 | verse **2:18**／base **2:3**（神賜福給第七日）／bonus 由 CC 回報候選 |

### GEN3｜8/31｜墮落與咒詛 — 本批最重

| 項目 | 內容 |
|---|---|
| 章旨 | 蛇的引誘；人吃了分別善惡樹的果子；神的追問與咒詛；神為他們做皮衣 |
| outline 建議 | 1-7 節（蛇的引誘，人吃了，眼睛明亮就知道赤身）／8-13 節（神呼喚「你在哪裡」，人推諉）／14-19 節（咒詛：蛇、女人、地）／20-24 節（神做皮衣給他們穿，趕出伊甸園 ✦） |
| **本章出口** | **3:21 耶和華神為亞當和他妻子用皮子做衣服給他們穿** |
| 雷區 A | **3:16 生產之苦、戀慕丈夫、丈夫必管轄你** — 對經歷難產、不孕、婚姻困難的玩家極易讀成「這是女人該受的」；「管轄」一句在教會場域是活的問題，會被讀成「神規定丈夫要管轄妻子」，婚姻中被壓制者讀到會覺得經文在說「這是應該的」 |
| 雷區 B | **3:17-19 終身勞苦、汗流滿面** — 易讀成「你的工作辛苦是活該」 |
| ★★ 核心框架（必寫進導讀） | **3:16-19 描述的是關係破裂後的「現況」，不是神設計的「理想」。** 創 2 才是理想（骨中的骨、肉中的肉）。咒詛在描述世界壞掉之後變成什麼樣子，**不是在規定它應該是什麼樣子** |
| 框架適用性 | 此框架同時解掉 3:16 與 3:17-19——沒有人會說「終身勞苦是神規定工作應該痛苦」，同樣邏輯適用於 3:16 的管轄 |
| 處理 | 導讀**忠實呈現全部咒詛，不軟化**。但須明寫：這是在說世界為什麼變成這樣，**不是在說你個人的遭遇是懲罰** |
| 情境題方向 | **路徑 B**，錨定 3:21。方向：你有沒有在最狼狽、最想躲起來的時候，被誰安靜地遮蓋過 |
| ❌ 絕對禁止 | 任何把玩家的具體苦難連結到咒詛的措辭 |
| ★ 時序是信息 | 3:21 在宣告咒詛「之後」。導讀須讓這個時序清楚——神先說了那些重話，然後親手為他們做衣服 |
| 選節建議 | verse **3:21**／base **3:9**（耶和華神呼喚那人：你在哪裡）／bonus 由 CC 回報候選 |
| ⚠️ 特別要求 | 本章生成後**必須主動回報 3:16 在 outline 中的實際措辭**，交內容視窗確認力度 |

## 五、經文來源紀律

### 唯一正確來源

```
https://rcuv.hkbs.org.hk/CUNP1/GEN/{章}/
```

**★ 驗檔內識別區塊為 `CUNP1|新標點和合本(神)`**，不可只看 title 或 HTTP 200。
（`/CUNP_1/` 底線路徑回的是和修版，title 前半相同）

### 落檔處理

| 項目 | 規範 |
|---|---|
| 逐字 | 原樣落檔，不改字、不改標點 |
| 異體字 | 「裏」一律改「裡」 |
| 敬空 | U+3000 移除 |
| `<sup title="...">` | 譯註，**一律剝除、不得採用**；但須主動列出哪些選節帶註 |
| `<ins>` | 和合本小字補字，**屬正文，一律保留** |
| 「甚麼」 | 照原文，不寫「什麼」 |

### ★ 「耶和華神」不帶連接字元（已驗證）

hkbs CUNP1 創 2 全章 11 處**全部直接相連**，無 U+FF0D、無 U+2014、無全形空格。
**GEN 落檔此結構不加任何連接號。**

同位語連接號僅用於「主－救主」「主神－全能者」這類**頭銜同位語**；
「耶和華神」是名字＋稱謂直接複合，兩者不可類推。

### ★ 選節檢查（強制）

每個選節落檔後逐節檢查並回報：

| 檢查項 | 不通過的處理 |
|---|---|
| 句末是否為句號／驚嘆號／問號 | 逗號、頓號、分號結尾 → 停下回報 |
| 引號是否在該節內閉合 | 未閉合或孤立閉引號 → 停下回報 |
| 是否為跨節括號插入語 | 開括號在前節 → 停下回報 |
| 是否帶 `<sup>` 小字註 | 一律主動列出（資訊，非缺失） |

**★ 標點不完整時的正確作法是換節或擴節，絕不改標點。**

### 字元規範

| 項目 | 規範 |
|---|---|
| 破折號 | 非經文區雙 `——`(U+2014×2)；**單一 U+2014 = 0** |
| U+FF0D | 非經文欄禁用；經文欄照原文（本批預期為 0） |
| U+2500 | 內容欄 0 |
| 欄位歸屬 | 「」內逐字引自和合本 → 經文欄；引號外自寫 → 非經文欄 |

## 六、BOOK_INTRO（本批必做）

依 PM 格式規則 v2：單行短字串、不以句號結尾、40 字內、補充用全形括號內嵌、
兩層用分號、非經文區禁頓號。

```
GEN: {
  author: '不詳（經文未署名，傳統歸摩西）',
  time: '不詳（經文未提供成書時間線索）',
  place: '不詳',
  theme: '起初——世界從哪裡來，人為什麼會變成這樣，神從沒有離開',
  audience: '未指名（記述以色列先祖的起源，也記下全人類共同的開頭）',
},
```

**爭議欄位處理**：作者傳統歸摩西但經文未署名，照 PM 規則寫「不詳＋傳統歸屬」。
成書時間與地點皆無經文線索，寫「不詳」不加推測。

```
choices[A,B,C,D] / responses{A,B,C,D}
reflectionTitle / reflection
baseItem{emoji,name,desc,slot} / bonusItem{同}
```

| 項目 | 規範 |
|---|---|
| outline 條數 | 3-4 條，範圍**連續無缺口**、涵蓋全章 |
| outline 內容 | 每條須涵蓋該範圍**全部重點**，不得只摘安全的一半 |
| ✦ | 每章恰 1 個，須標在 focus 實際聚焦的那一條 |
| choices | 四選項涵蓋不同信仰成熟度；**D 一律保留「我不確定／做不到」的出口** |
| responses | 每條結尾收在「情緒有重量的小步」——真人說得出口的一句話 |
| reflection | 每章恰 1 個 `\n\n` 分段 |
| 三節不共節 | verse / base / bonus 不得引用同一節；皆限本章內、**不跨章** |
| 稱謂 | 非經文稱神「祂」、禱告「祢」；**經文原文的「他/你」照留** |
| ★ 裝備名 | **只取該節既有詞語，不得添加經文沒有的意象** |
| 用字 | 「裡」不用「裏」；新增區塊 `裏 = 0` |
| 標點 | 經文欄保留原文標點；非經文區不得出現頓號 |
| readTime | 3-6 分鐘 |
| emoji | 新裝備 emoji×slot 須對全檔既有＋批內查重 |

## 八、全批通用禁止事項
