這頁在示範什麼

  • 營火默想：底圖是今天新生的「空營地」，小旅人坐姿背影是另一張獨立的圖疊上去的，火光、火星、星星都是 CSS。
  • 衣櫃分層：身體、三件外袍、兩種頭飾各是獨立去背圖，靠同一張定裝圖生成後再對齊，所以能任意組合。坐姿背影還沒有分層，衣櫃換裝目前不會影響營火畫面。
  • 待機動畫：呼吸、眨眼、斗篷、油燈都是對分層圖做的 CSS 動畫；眨眼是用膚色蓋眼睛，位置手動對過。
  • 頭飾與放下的帽兜位置是我手動微調的，正式資產要在定裝圖上標錨點再生。
